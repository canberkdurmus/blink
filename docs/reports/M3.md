## Notes for the owner

- **An interrupted session left work behind.** The 2026-11-21 session hit its usage cap and left
  PR #17 (RATE-1/2/3), a FILE-8 branch and an uncommitted interop worktree, none of it recorded in
  PROGRESS.md. This session re-implemented RATE-1/2/3 (#18; #17 was closed as superseded: it was
  red on Windows), ported FILE-8 onto it (#20, keeping its `notify` design, ADR 0018) and committed
  the interop work (#19, ADR 0017). The start-of-session check now also looks at `git worktree list`
  (CLAUDE.md "Learned").
- **digiKam interop is deferred** (ADR 0017). digiKam has no headless import. The digiKam sidecar
  dialect is covered by the RATE-4 fixture, and the exiftool oracle covers what Blink writes. SPEC §6
  names digiKam as a nightly oracle. Please say if you want a scripted-GUI approach instead.
- **FILE-9 vs RATE-3** (ADR 0015 §7): an undo back to the session-start values restores the
  original bytes, `xmp:MetadataDate` included, so after undo-all the file equals what other apps
  last saw. Strictly, FILE-9 asks for a new MetadataDate on every change Blink makes.
- **Undo history is per folder** (ADR 0016): opening another folder starts a new history. File
  operations (FILE-1/2, M4) join the history when they exist.
- **Label keys toggle** (ADR 0016): pressing the label an item already has clears it. SPEC §5.2 has
  no "clear label" key.
- **Config file** (ADR 0016): `config.toml` in the config directory sets `pick_value` (1–5),
  `auto_advance`, `sidecar_style` and `[labels]` names. New runtime dependency `toml` (serde core,
  no derive). A missing `serde` feature broke standalone builds of `blink-runtime` (hidden by
  workspace feature unification, caught by the nightly interop's `blink-cli` build). #25 fixed it,
  and CI's guard job now builds each shipped crate alone.
- **New runtime dependency `notify` 9.0.0** (CC0-1.0, ADR 0018) watches the open folder. Blink also
  checks each sidecar right before its debounced write, so another app's change is never
  overwritten even when the watcher event comes late.
- **PERF-7** (ADR 0019): 101 ms on CI, 113 ms here. Most of it is the 100 ms debounce (FILE-6:
  ≤ 250 ms). The local "+11 %" line below compares this machine's fsyncs with the CI runner's
  baseline. CI's own perf job is the regression check, and it passed (run 44965790605: 101.1 ms).
- **Perf noise on CI.** Two PERF-7 PR runs had every metric 15–30 % slow, including PERF-4, which
  the PR doesn't touch. A rerun on the same tree was back to baseline (PERF-1 168 ms, PERF-5
  2018 ms). No baseline was raised.
- The absolute M2 budgets still wait for your laptop (HUMAN_TODO). Locally (Ryzen 7 PRO 7840U)
  every budget, PERF-7 included, is met (table below).
