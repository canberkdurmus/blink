## Notes for the owner

- **Spec interpretation (ADR 0003):** `cargo xtask trace` requires coverage only for IDs of earlier
  milestones, IDs ticked in PROGRESS.md, and the gate milestone (`--gate Mn`). Requiring every §4/§7
  ID from day one would leave `main` permanently red.
- **Tag naming (ADR 0005):** M0 is `v0.0.1-m0` (per the gate). Later milestones use `v1.0.0-mN` (per §9).
- **Nightly soak/fuzz/interop** run as placeholder jobs until the code they exercise exists (M2/M3).
  They report "nothing to run yet" and succeed.
- **HUMAN_TODO.md** has 2 items: branch protection on `main`, and allowing Actions to open PRs (weekly deps PR).
